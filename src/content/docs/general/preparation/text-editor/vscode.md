**最推荐的文本编辑器**，全能型，支持简体中文，跨平台（Windows / Linux / Mac）。

![VS Code](https://code.visualstudio.com/assets/docs/getstarted/getting-started/terminal-new-file.png)

功能强大，插件生态丰富，对新手非常友好。启动速度可能不是最快，但完全可以接受。

:::tip[保存提示]
编辑完后记得保存文件。VS Code 会在未保存的文件标签上标记白点，提醒你尚未保存。快捷键 `Ctrl + S` 保存，也可以在菜单中开启自动保存。
:::
